# 🛡️ Politique de Sécurité (Security Policy)

## Versions Prises en Charge

Nous publions régulièrement des correctifs de sécurité pour la dernière version stable de **Steam Big Picture Manager**.

| Version | Supportée |
| :--- | :--- |
| `v2.x` | ✅ Oui |
| `< v2.0` | ❌ Non |

---

## 🔒 Signalement d'une Vulnérabilité

La sécurité de vos installations Steam et de vos données locales est une priorité absolue.

Si vous découvrez une vulnérabilité de sécurité :

1. **Ne créez PAS d'Issue publique** pour un problème critique de sécurité.
2. Signalez la vulnérabilité de manière responsable en créant un [Security Advisory GitHub Privé](https://github.com/Flaimeur/steam-big-picture-manager/security/advisories/new).
3. Veuillez inclure dans votre signalement :
   - Une description détaillée de la faille identifiée.
   - Les étapes ou le script de reproduction (PoC).
   - Les systèmes d'exploitation affectés (Windows, SteamOS, Linux, macOS).
   - L'impact potentiel sur l'environnement Steam de l'utilisateur.

---

## ⚡ Engagement de Réponse

- Nous accusons réception des signalements de sécurité sous **48 heures ouvrées**.
- Une analyse d'impact et un calendrier de correction vous seront communiqués rapidement.
- Les contributeurs signalant des failles de manière responsable seront crédités dans les notes de version.
